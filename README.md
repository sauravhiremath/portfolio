# Portfolio

Personal site at [sauravmh.com](https://sauravmh.com)

## Local development

Run `bun install`, then `bun run dev`. Open `http://localhost:4321/projects` to view the projects page. Source edits update the page in the browser.

The local Servicemon entry is `portfolio/web`. Use `servicemon start portfolio/web` or `servicemon stop portfolio/web` to control it.
